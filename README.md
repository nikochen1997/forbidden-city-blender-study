# 故宫现存格局 Blender 外观研究

这里保存持续制作过程中已归档的旧阶段工程，供查看、编辑和继续研究。项目仍在完善，保留大量灰色体块和未完成细部，不是测绘级绝对复原，也不是故宫博物院官方项目。

制作范围为午门、宫城内建筑与护城河，不新增午门以南建筑。最终交付以高清全宫图与相关局部图为主。

## 使用

解压某一阶段，用本地 Blender 打开包内模型即可编辑或渲染。模型使用程序生成的材质，不需要付费云服务；已用 Blender 4.5.15 LTS 实际打开并试渲染各公开副本。

历史生成脚本和参数用于理解制作过程。完整历史核验还依赖未再分发的原版研究资料及历史状态文件，不能将这份公开归档当作全部阶段从零生成的可复现环境。Blender 程序与插件请从各自官方渠道取得，仓库不附安装包。

公开模型仅清除了文件选择器目录、渲染输出路径中的本机信息；公开 PNG 清除了私人文本元数据，像素数据不变。模型几何、材质、镜头和可见性已对照原件核验。原始审计清单记录的是处理前 SHA；公开下载请以 Release 的 SHA256 清单为准。

公开 manifest、profile 与少量代码中的本机项目根路径改为相对路径，原 SHA 与公开副本 SHA 分别记录，其他事实与参数保留。
